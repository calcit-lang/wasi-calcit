# Upgrade checkpoint: Calcit 0.13.77

Tracked by calcit-lang/calcit#753. Agent: `codex-01a06d2e`.

## English

This checkpoint upgrades `wasi-calcit` from Calcit 0.8.50 to the exact
`calcit = "=0.13.77"` crate and adapts the host integration to the current
Calcit API. It also moves the example compact snapshot to the conventional
`examples/calcit.cirru` path and migrates it only through the exact CLI chain
`0.13.50 -> 0.13.51 -> 0.13.77`.

The native host passes formatting, clippy with warnings denied, tests,
snapshot execution, eval mode, and JavaScript emission. The WASI Preview 1
target (`wasm32-wasip1`) also builds successfully with Rust 1.97.1.

Actual WASI execution remains blocked: both this upgraded binary and the
official Calcit v0.13.77 `cr-wasm` binary trap in
`runner::preprocess::preprocess_list_call` with an out-of-bounds linear-memory
access under Wasmtime 18.0.3. The independently reproduced core bug is tracked
in calcit-lang/calcit#763. No pull request should claim complete WASI validation
until that upstream issue is resolved.

## 中文

这个 checkpoint 将 `wasi-calcit` 从 Calcit 0.8.50 升级到精确版本
`calcit = "=0.13.77"`，并将宿主集成适配到当前 Calcit API。示例 compact
snapshot 移到约定路径 `examples/calcit.cirru`，迁移过程只使用精确 CLI 链
`0.13.50 -> 0.13.51 -> 0.13.77`。

原生宿主已经通过格式检查、以 warning 为错误的 clippy、测试、snapshot
执行、eval 模式和 JavaScript 生成；WASI Preview 1 目标
`wasm32-wasip1` 也能在 Rust 1.97.1 下成功构建。

实际 WASI 执行仍被上游问题阻塞：升级后的二进制与 Calcit v0.13.77 官方
`cr-wasm` 都会在 Wasmtime 18.0.3 中于
`runner::preprocess::preprocess_list_call` 发生线性内存越界。独立复现的核心
问题记录在 calcit-lang/calcit#763。在该上游问题解决前，不应创建声称 WASI
运行验证完整通过的 PR。
